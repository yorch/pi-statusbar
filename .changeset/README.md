# Changesets

Hello and welcome! This folder has been automatically generated via `npx changeset init`. It contains two files:

1. The `config.json` file. This file configures what files are published and how they are versioned.

2. The `README.md` file. This file is the one you are reading right now.

The `config.json` file has been configured to publish only public packages, ignore private packages and use the GitHub changelog generator.

More information can be found on the [changesets documentation](https://github.com/changesets/changesets/blob/main/docs/config-file-options.md).
